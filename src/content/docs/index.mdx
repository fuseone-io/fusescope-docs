## What you get

<CardGrid>
  <Card title="APM and tracing" icon="random">
    Latency, error rate, throughput and Apdex per service, a trace explorer, flame
    graphs and trace funnels.
  </Card>
  <Card title="Metrics, logs and dashboards" icon="analytics">
    Log pipelines and live tail, metrics with Query Builder, PromQL or ClickHouse SQL,
    and dashboards over all of it.
  </Card>
  <Card title="Alerts" icon="warning">
    Alert on metrics, traces, logs and exceptions, with Slack, PagerDuty, Opsgenie,
    Jira, MS Teams, webhook and email channels.
  </Card>
  <Card title="OpenTelemetry-native" icon="rocket">
    Send OTLP over gRPC or HTTP from any OpenTelemetry SDK or collector. Data lands in
    ClickHouse.
  </Card>
  <Card title="PostgreSQL or SQLite" icon="database">
    Keep users, dashboards and alert rules in SQLite on a single node, or in PostgreSQL
    to run several backend replicas.
  </Card>
  <Card title="Single sign-on" icon="padlock">
    OpenID Connect with Microsoft Entra ID, Keycloak, Okta, Auth0 or any OIDC provider,
    with group to role mapping.
  </Card>
</CardGrid>

FuseScope is built by [FuseOne](https://github.com/fuseone-io) as a hard fork of
[SigNoz](https://github.com/SigNoz/signoz). Its source code is MIT licensed.
