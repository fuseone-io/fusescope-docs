**Use this page when** someone sent you a dashboard as a `.json` file and you want to
add it to FuseScope, or when you edit a dashboard as JSON, keep dashboards in Git, or
write one by hand. FuseScope ships no built-in dashboard templates: a dashboard shared
as JSON is how you reuse one.

## Import a dashboard

<Steps>

1. Open **Dashboards** in the sidebar and click **New dashboard**.
2. Click the **Import JSON** tab.
3. Paste the JSON into the editor, or click **Upload JSON file** and pick the `.json`
   file.
4. Click **Import and Next**. FuseScope creates the dashboard and opens it.

</Steps>

If the JSON can't be read, the dialog shows *Error loading JSON file*, or
*Invalid JSON* for an uploaded file that isn't JSON at all.

## Export a dashboard

Open the dashboard and click **JSON** in its toolbar. The **Dashboard JSON** panel
opens on the right; click **Download** to save it as a `.json` file, ready to import
elsewhere. **Copy** puts the same JSON on the clipboard. You can also edit the JSON
there and click **Apply changes**; see
[Export and edit as JSON](/dashboards/dashboards/#export-and-edit-as-json).

## Format

The JSON has `name`, `schemaVersion` (`"v6"`), `image`, `tags` and a `spec` with the
display name and description, `duration`, `refreshInterval`, `variables`, `panels` and
`layouts`. Panels are referenced from layouts by ID. A shortened example, with the panel's
options and queries left out:

```json
{
  "name": "checkout",
  "schemaVersion": "v6",
  "tags": [{ "key": "team", "value": "payments" }],
  "spec": {
    "display": { "name": "Checkout" },
    "panels": { "p1": { "kind": "Panel", "spec": { "plugin": { "kind": "signoz/TimeSeriesPanel" } } } },
    "layouts": [
      {
        "kind": "Grid",
        "spec": {
          "display": { "title": "Overview" },
          "items": [{ "x": 0, "y": 0, "width": 6, "height": 6, "content": { "$ref": "#/spec/panels/p1" } }]
        }
      }
    ]
  }
}
```

Panel kinds keep their [internal names](/configuration/config-file/#internal-names), such as `signoz/TimeSeriesPanel`.

The grid is 12 columns wide. Import also accepts just the `spec` object, and JSON
exported from older versions, which is converted on import.

<Aside>
  An imported dashboard's `image` must be one of FuseScope's built-in icons or a base64
  image.
</Aside>
