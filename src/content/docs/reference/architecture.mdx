## Components

### Backend

`fusescope server`, image `ghcr.io/fuseone-io/fusescope`. It serves the web UI and the
API on port 8080, runs queries against ClickHouse, evaluates alert rules and sends
notifications through its embedded Alertmanager. It keeps users, dashboards, alert rules
and SSO domains in the [metadata store](/configuration/metadata-store/).

Its OpAMP server on port 4320 pushes collector configuration managed in the UI, such as
log pipelines, to the collectors.

### FuseScope Collector

`ghcr.io/fuseone-io/fusescope-collector`, from
[fusescope-collector-server](https://github.com/fuseone-io/fusescope-collector-server), a
distribution of the OpenTelemetry Collector. It runs in two roles:

- **Agents**, a DaemonSet (`fusescopeAgent`): each node's pod logs, host metrics and kubelet
  stats, and optionally OTLP from the node's pods over TLS 1.3 with a token. They send to the
  gateway over mTLS and write nothing.
- **The gateway**, a Deployment (`fusescopeCollector`): it receives from the agents and from
  browsers and mobile apps (RUM), computes span metrics, and writes traces, metrics and logs to
  ClickHouse. It scales horizontally.

It receives only OTLP. During a SigNoz migration, the gateway can also serve plaintext OTLP
inside the cluster, by explicit opt-in.

### Schema migrator

The collector image also ships `fusescope-schema`, which owns the ClickHouse schema. The Helm
chart runs it as a Job at install and upgrade, and the gateway waits until the schema is migrated
before it writes.

### ClickHouse

Stores all telemetry in the `signoz_traces`, `signoz_metrics`, `signoz_logs`,
`signoz_meter` and `signoz_metadata` databases. The chart deploys it with the Altinity
ClickHouse operator; `clickhouse.layout` sets shards and replicas, and
`clickhouse.coldStorage` moves older data to S3 or GCS. Use `externalClickhouse` to point
at an existing cluster.

### ZooKeeper

ClickHouse uses ZooKeeper to coordinate `Replicated*` tables and to run `ON CLUSTER` DDL
across the cluster. The chart installs it with ClickHouse (`clickhouse.zookeeper.enabled`);
`clickhouse.externalZookeeper` points at an existing ensemble.

### Metadata store

SQLite on a persistent volume for a single backend replica, or PostgreSQL for several. See
[Metadata store](/configuration/metadata-store/).

## Ports

| Component | Port | Use |
|---|---|---|
| Backend | 8080 | UI and API |
| Backend | 4320 | OpAMP for collectors (processor settings) |
| Backend | 4321 | OpAMP over TLS 1.3, the ingest policy for RUM |
| Backend | 9090 | Prometheus metrics of the backend itself |
| Gateway | 4322 | The agents' listener: OTLP/gRPC, mTLS and a token |
| Gateway | 4319 | RUM, TLS |
| Gateway | 4317, 4318 | Plaintext OTLP, only for a SigNoz migration and only when turned on |
| Agent | 4317, 4318 | OTLP from the node's pods, TLS 1.3 and a token, when turned on |
| Gateway, agent | 13133 | Health check |
| ClickHouse | 9000 | Native protocol used by the backend and collector |
