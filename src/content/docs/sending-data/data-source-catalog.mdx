**Use this page when** you opened **Get Started** to add a data source, or want to know
which setup page covers what you want to monitor.

<Aside type="note" title="Available from v0.153.0">
  On older versions the **Connect data source** buttons open these docs instead, and the
  tables below are the catalog.
</Aside>

The data source catalog is the **Get Started** page, at `/get-started`. The old address,
`/get-started-with-signoz-cloud`, redirects to it.

It is organised by **goal**: you pick what you want to see in FuseScope, then the
technology you use, and the entry opens the FuseScope setup page for it. Every entry
ends up sending OpenTelemetry data over [OTLP](/fusescope-docs/sending-data/otlp/) to
your own FuseScope collector, with no ingestion key.

## Run a collector

A collector next to your applications batches, retries and enriches data before it
reaches FuseScope.

| Entry | Setup page |
|---|---|
| Docker | [Collector on Docker](/fusescope-docs/sending-data/collector-docker/) |
| Linux VM (systemd) | [Collector on a VM](/fusescope-docs/sending-data/collector-vm/) |
| An existing OpenTelemetry Collector | [OTLP › From another collector](/fusescope-docs/sending-data/otlp/#from-another-collector) |

<Aside>
  Nothing in **Get Started** is required: FuseScope shows data as soon as it reaches the
  collector. Close it and come back any time.
</Aside>

## Check that data arrives

Within a minute of sending, look for the service under **Services**, or for the data in
the [Traces](/fusescope-docs/explore/traces/), [Logs](/fusescope-docs/explore/logs/) or
[Metrics](/fusescope-docs/explore/metrics/) explorers.
