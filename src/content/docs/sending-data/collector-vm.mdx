**Use this page when** your applications run on a virtual machine or bare-metal server and you
want a collector on that machine to forward their telemetry to FuseScope.

<Aside type="caution" title="No supported destination outside the cluster yet">
  The FuseScope chart exposes no OTLP endpoint outside the Kubernetes cluster that runs
  FuseScope. Its only public endpoint is Real User Monitoring, for browsers and mobile apps. A
  collector on a VM or server outside that cluster has nowhere supported to send to yet, so this page
  has no configuration to copy. It will, once FuseScope offers an authenticated external
  endpoint.
</Aside>

## Inside the cluster

Applications and collectors that run as pods in the cluster that runs FuseScope send to the
FuseScope agent on their node, over TLS 1.3 with a bearer token:

- [OTLP](/sending-data/otlp/): the endpoint, the credentials, and a collector you run in the
  cluster forwarding to the agent.
- [Kubernetes](/sending-data/kubernetes/): pod logs and node metrics from the FuseScope agents.
